# 🍅 Pomora – Pomodoro Timer & Study Tracker

> **Focus deeply. Study consistently. Grow daily.**

Pomora is a modern productivity web application designed for students and self-learners who want to stay focused using the **Pomodoro Technique** while tracking daily study goals, study streaks, and overall productivity.

## ✨ Features

- ⏱️ 25/5 Pomodoro Timer
- ▶️ Start, Pause & Reset Controls
- 🔁 Automatic Focus & Break Sessions
- 🎯 Daily Study Goal Tracker
- 🔥 Study Streak Counter
- 📊 Study Analytics Dashboard
- 💾 LocalStorage Support
- 🌙 Dark Mode
- 📱 Fully Responsive Design

## 🚀 Getting Started

### Clone the Repository

```bash
git clone https://github.com/praachipandey/pomora.git
cd pomora
```

### Run Locally

Open **index.html** in your browser.

No additional setup is required.

---

## 🎯 How to Use

1. Set your daily study goal.
2. Click **Start** to begin a focus session.
3. Stay focused until the timer ends.
4. Take a short break.
5. Repeat the cycle and track your progress.
